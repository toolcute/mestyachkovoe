## ✨ Основные возможности

* **Вся Россия!:** Изначальная идея приложения была в легкой ленте Уральских новостей, с рег.фильтрацией других регионов. По немногочисленным просьбам я сделал возможность выбрать другой федеральный округ в настройках — пункт «ФедОкруг ленты» (Урал, Центральная Россия, Приволжье, Сибирь, Московская область, Юг России, Северный Кавказ, СЗФО и Дальний Восток).
* **Дизайн Material 3 Expressive:** крупные выразительные формы, плавные пружинные анимации, новая типографика Nunito, тональные карточки и переработанный профиль CuteID.
* **Рег.фильтрация:** Я попытался изолировать новости других областей и назойливой фед. повесточки. Только то, что происходит у вас дома.
* **Локальная песочница:** Автоматический фильтр скрывает нежелательные новости, упоминания Священной ВОйны и чужих регионов.
* **Bottom Sheet:** Читайте полные тексты новостей прямо в приложении, не открывая лишний раз браузер!
* **Кастомизация интерфейса:** Переключение тем оформления, выбор названий и иконки приложения на рабочем столе.
* **Фоновые уведомления:** Гибкая настройка оповещений по регионам(!) и важности новостей. Есть режим 3-4 важных уведомлений в день.
* **Кеш:** Быстрая загрузка ленты благодаря кешированию, ручная очистка и автоочистка с выбором периодичности.
* **Реальное время публикаций:** Время в ленте берётся из RSS/Atom (`pubDate`, `published`, `dc:date`, `updated`), а старые посты «Местечка» — из даты в `<guid>`. Лента сортируется строго по времени выхода новости.
* **Любимое:** Сердечко на карточке сохраняет статью, а кнопка «Источник в любимое!» — RSS-ленту источника. Любимые источники открываются отдельной мини-лентой без умной фильтрации.
* **CuteID (CID):** Необязательный аккаунт через Telegram-бота CuteIDBot. Любимое синхронизируется между устройствами через `toolcute/CuteID/users.json`, имя можно сменить в профиле.
* **Автообновление:** Приложение само проверяет релизы на GitHub и обновляется по воздуху начиная с версии **v1.09**.
